# Лабораторная работа № 2

**Задача:** оценивать концентрацию продукта по 16 каналам телеметрии и уже доступной истории лабораторных измерений,
учитывая динамику работы печи.


## Запуск

1. Установите **Python 3.10 или новее**. Рекомендуется отдельное виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell: `.venv\Scripts\Activate.ps1`; Linux/macOS: `source .venv/bin/activate`.

2. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Убедитесь, что четыре CSV доступны в папке `data/`, либо их ссылки открыты для скачивания.
4. В каталоге репозитория запустите:

   ```bash
   jupyter lab
   ```

5. Откройте `LR2.ipynb` и выполните **Run All** последовательно сверху вниз. Графики и таблицы отображаются внутри
   ноутбука, дополнительные CSV с результатами сохраняются в созданную папку `results/`.

Выполнение TCN может быть медленнее табличных моделей; скорость зависит от CPU/GPU. Для повторяемости в коде
зафиксированы генераторы случайных чисел. Численные результаты могут незначительно отличаться из-за версий библиотек и
вычислительной среды.

## Что делает ноутбук по разделам задания

- **2.1 EDA:** исследование структуры минутной и редкой телеметрии, пропусков, аномалий, трендов, сезонности,
  распределения целевой переменной, частоты проб, синхронизации и корреляций с временными лагами. Статистические методы
  ADF/KPSS/ACF/PACF связаны с первой лабораторной.
- **2.2 Признаки:** лаги, среднее/стандартное отклонение/минимум/максимум в скользящих окнах, абсолютные и относительные
  изменения; данные обрабатываются без использования будущих наблюдений. Дополнительный отбор/PCA не применяется как
  необязательный.
- **2.3 Модели:** Random Forest и XGBoost на табличных временных признаках; TCN на многомерных окнах истории. Модели
  сравниваются через календарную CV; тест не используется для их выбора.
- **2.3 Качество:** MAE, RMSE, MAPE с защитой от деления на ноль, WAPE, доля правильно определённых направлений, графики
  динамики, диагностика остатков, SHAP, permutation importance, стоимость вычислений. Обычные AIC/BIC неприменимы к трём
  выбранным моделям; их не подменяют фиктивными значениями.
